# AGENTS.md

## Project overview

- Generates CSS custom properties (`--ph-icon-<name>`) and `.ph-<name>` classes for [Phosphor Icons](https://phosphoricons.com/).
- `build-css.mjs` downloads the upstream `phosphor-icons.zip`, optimizes each SVG with SVGO and writes `dist/phosphor-icons-{regular,fill,duotone,thin,light,bold}.css` (plus `.min.css`).
- The build also copies the CSS and writes `icon-list.json` into `docs/` (the GitHub Pages demo). These generated files are committed; `dist/` is not.
- Do not hand-edit `docs/phosphor-icons-*.css` or `docs/icon-list.json`. Change `build-css.mjs` and run `npm run build`.

## Commands

- `npm install` – install dev dependencies (`package-lock = false`, so no lockfile is committed).
- `npm run build` – regenerate `dist/` and the generated files in `docs/` (needs network access to GitHub).
- `npm run lint` – HTMLHint, Stylelint and ESLint.
- `npm run prettier` – format CSS, HTML, JS, JSON and YAML.
- `npm run spellcheck` – cspell. Add genuine new words to `.cspell.json`.
- `npm run serve` – serve the `docs/` demo locally.

## Environment

- Node.js version is pinned in both `.nvmrc` and `package.json` (`volta.node`). Keep them in sync.

## CSS

- Always list CSS attributes in alphabetical order.
- This also applies to CSS generated by `build-css.mjs` and code samples in `README.md` and `docs/index.html`.

## HTML

- Always use lowercase attributes.
- The viewport meta tag should be `<meta name="viewport" content="width=device-width" />` (no `initial-scale`).

## GitHub Actions

- See `.github/AGENTS.md` for workflow and Dependabot conventions (SHA-pinned actions, `persist-credentials: false`, least-privilege `permissions`).

## Git and pull requests

- Use meaningful, descriptive branch names that summarize the change, e.g. `fix/canonical-url` or `chore/update-actions-and-deps`. Avoid random or auto-generated names.
- Keep commits focused and write clear commit messages.
